# 預設排軸

這個資料夾放「排軸器內建、可直接選用」的排軸檔。網頁上按「預設排軸」即可看到並加入。

## 如何新增

1. 在排軸器編輯好副本後，按「匯出」下載 JSON 檔。
2. 將檔案放進本資料夾（副檔名必須是 `.json`），檔名建議使用英文或數字，例如 `m1s-mitigation.json`。
3. 開發中：重新整理網頁即可看到；正式版：重新執行 `npm run build`。

## 注意事項

- 一個檔案可以包含多個副本，會分別列出。
- 格式錯誤的檔案不會被載入，網頁上會顯示錯誤原因。
- 本資料夾的檔案會打包進網頁並納入版本控制；個人暫存請放在 `export_data/`（不會被 commit）。
